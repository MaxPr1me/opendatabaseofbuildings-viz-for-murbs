# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

This is a research tool that processes publicly available geospatial data.
It does not handle authentication, personal data, or network services in
production deployments.

If you discover a security vulnerability, please report it by opening a
private issue or contacting the maintainers directly.

Do not open a public issue for security vulnerabilities.
